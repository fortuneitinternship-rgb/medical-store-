# MediHub — E-Commerce Frontend

A responsive medical e-commerce frontend built using
React, Vite, JavaScript, Bootstrap and React Router.

## Features

- Responsive homepage
- Product search and category filters
- Reusable components
- Add to Cart
- Cart count using localStorage
- React Router navigation
- Coming Soon pages
- Responsive CSS

## Technologies

- React.js
- Vite
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- React Router
- CSS
- Git & GitHub
